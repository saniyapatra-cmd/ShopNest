🛍️ ShopNest — Your Everyday Marketplace

ShopNest is a modern e-commerce website built using HTML, CSS, and JavaScript. It provides a clean and user-friendly shopping interface where users can explore products across different categories.

The project is designed to demonstrate frontend web development skills through an attractive layout, product browsing interface, and shopping-related features.

🌟 Features

- 🏠 Modern Homepage — A welcoming hero section with shopping promotions.
- 🛒 Product Catalog — A dedicated section for displaying featured products.
- 📂 Product Categories — Browse Fashion, Technology, Home & Living, Beauty, Fitness, and Accessories.
- 🔍 Product Search — Search interface for finding products.
- 🎯 Product Filtering — Category and price filtering options.
- ↕️ Product Sorting — Options to sort products by price and name.
- 🛍️ Shopping Cart — A cart interface for reviewing selected products.
- 👀 Product Quick View — A modal interface for viewing product details.
- 🎉 Special Offers — A promotional section for discounts and newsletter subscriptions.
- 📧 Contact Form — A form interface for customer inquiries.
- 📱 Responsive Design — CSS styling intended to support different screen sizes.
- 💬 WhatsApp Contact — A shortcut for contacting customer support.
- 🔗 Social Media Links — Links to popular social platforms.

Note: The interactive features depend on the JavaScript implementation. Responsive behavior should be tested on different screen sizes.

🛠️ Technologies Used

- HTML5 — Structures the website and its content.
- CSS3 — Provides styling, layouts, colors, and visual effects.
- JavaScript — Intended to power interactive features.
- Google Fonts — Inter and Playfair Display typography.
- Unsplash — External images used throughout the website.

🚀 How to Run Locally

Follow these steps to run the website on your computer:

1. Clone or download this repository.
2. Open the project folder.
3. Make sure "index.html", "style.css", and "script.js" are in the correct locations.
4. Open "index.html" in your web browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

📤 How to Upload to GitHub

1. Create a new repository on GitHub.
2. Give it the name "ShopNest".
3. Upload "index.html", "style.css", "script.js", and "README.md".
4. Commit your changes.
5. Open your repository's Settings → Pages.
6. Select Deploy from a branch, choose "main" and "/ (root)", and save.

After deployment, GitHub will provide a URL for your live website.
